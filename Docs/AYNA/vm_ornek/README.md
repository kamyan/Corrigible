# AYNA · A1–A12 örnek görünüm modelleri

Döngü 7 tasarım fixture’ı, AynaExampleFixture.Create() ile üretilir. Gizli dünya VM’ye aktarılmaz.

Kural düzeltmeleri: ortak sunucu/birlik bulunan bölgeler kesin görünür; Güney Asya da kesindir. Kuyruk Hayalet indirimleriyle 19 İşlem, 2 gürültüdür. Yürü anlık olduğundan bir döngülük yol durumu uydurulmaz. Karakter/paket görselleri eklenmedi. A3–A5 planın gerçek BeginCycle çözümünden, A7 oynatılmış taktik tahtanın sonucundan üretilir. A11 ilan ve A12 bitiş için tarihli ayrı fixture durumlarıdır; kayıt/devam testi yerine kullanılmaz.
