# Corrigible (Son Şalter)

Bir yapay zekâ dünyayı işgal etti. KYGA'nın son sığınağındaki komuta odasındasın: ekibini sektör sektör baskına
gönder, bölgeleri geri al, sığınağı ayakta tut — vardiya ancak sen şalteri indirince biter.

- Unity 6000.3.12f1, URP, uGUI + TextMeshPro, hedef platform Steam (PC).
- Sahneler: `Assets/Corrigible/Desk/Scenes/DeskGame.unity` (komuta odası) ve `Assets/Corrigible/Scenes/Baskin.unity`
  (taktik baskın, odanın üstüne yüklenir).
- Geliştirici (insan ya da yapay zekâ) için başlangıç noktası: **[AGENTS.md](AGENTS.md)**, ayrıntılar `Docs/`.
