# Corrigible (Son Şalter)

Bir yapay zekâ dünyanın ağlarına sızdı. KYGA'nın kriz masasındasın: onu bul, gözlemle, hizala ya da sil —
ama ekranların sana yalan söyleyebileceğini, rakibinin seni önceki oyunlarından tanıdığını unutma.

- Unity 6000.3.12f1, uGUI + TextMeshPro, hedef platform Steam (PC). Sahne: `Assets/Corrigible/Scenes/Main.unity`.
- Tarayıcı prototipi ve denge araçları: `Prototype/`.
- Geliştirici (insan ya da yapay zekâ) için başlangıç noktası: **[AGENTS.md](AGENTS.md)**, ayrıntılar `Docs/`.
